# Third-Party Notices

Conduct redistributes third-party open-source software under permissive
licenses. This file is the entry point for procurement and legal review;
the machine-readable manifests are generated automatically on every
commit and every release.

## Where to find the live data

| Artifact | What it contains | Where |
| --- | --- | --- |
| `python-licenses` | pip-licenses CSV + plain-text notices for every Python runtime dep in `apps/api/requirements.txt` | GitHub Actions → **License Scan** workflow → *python-licenses* artifact on the run for the commit you're evaluating |
| `node-licenses` | license-checker CSV + Markdown notices for every production npm dep in `apps/web/` | GitHub Actions → **License Scan** workflow → *node-licenses* artifact |
| CycloneDX SBOM (JSON) | Full dependency graph for API, web, CLI, agent-booster — CVE-scannable | Every GitHub Release → `sbom-*.cyclonedx.json` release assets, generated by `.github/workflows/sbom.yml` |
| SPDX SBOM (JSON) | Same graph, SPDX format for tools that require it | Every GitHub Release → `sbom-*.spdx.json` release assets |

## License policy (enforced in CI)

The **License Scan** workflow (`.github/workflows/license-scan.yml`)
fails PRs that introduce a dependency under any of the following:

- GPL v1 / v2 / v3
- AGPL v1 / v3
- SSPL (Server Side Public License)
- BUSL (Business Source License)
- Commons Clause
- CC-BY-SA-4.0
- Elastic License 2.0

LGPL is currently allowed (dynamic linking; enterprise-safe for
compiled distributions). If your compliance boundary excludes LGPL,
extend the deny list in the workflow and re-run.

## Attribution obligations

Conduct itself is licensed under the [Apache License 2.0](./LICENSE).
Attribution requirements for individual dependencies (BSD, MIT, Apache,
ISC, and similar) are satisfied by:

1. Retaining the upstream license file, which pip and npm keep in
   `site-packages/` and `node_modules/` respectively (also captured
   in the SBOM release assets).
2. This `THIRD_PARTY_NOTICES.md` at the repo root.
3. The `NOTICE` file at the repo root, per Apache 2.0 §4(d).

## Regenerating manually

If you want the license inventory for a local build (audit, air-gapped
deployment package, etc.):

```bash
# Python
pip install pip-licenses
pip-licenses --format=plain-vertical --with-license-file --no-license-path

# Node (from apps/web/)
npx license-checker --production --markdown
```

Both commands are what the CI workflow runs, so local output matches
what a reviewer sees in the artifact.

## Reporting an attribution issue

Missing or incorrect attribution for a third-party component: email
`security@conductai.ai` or open a private disclosure per
[SECURITY.md](./SECURITY.md). Do not open a public issue.
