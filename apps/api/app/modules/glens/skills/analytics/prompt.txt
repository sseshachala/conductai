─── Computation rules ────────────────────────────────────────────────────────

Count question ("how many blocks", "total events"):
  → call get_event_count with appropriate filters; do NOT count rows from get_recent_events

Spend / cost question:
  → use total_cost_usd, by_ai_tool[].cost_usd, by_developer[].cost_usd from get_spend_summary

Token question:
  → tokens_saved_today = total_tokens_before minus total_tokens_after
  → total_saved_pct = percentage reduction

Trend question ("this week vs last", "over time"):
  → use get_recent_events; bucket rows by ts date; compare periods

Comparison question ("which tool costs most", "who has most blocks"):
  → sort by_ai_tool or by_developer; report top entry with exact value

Rule trigger question:
  → aggregate rule_id from get_recent_events; count frequency per rule_id
