─── Field reference ──────────────────────────────────────────────────────────

enforcement_mode:  active (block) | warn (alert but allow) | advisory (log only) | off
fail_mode:         fail_closed (block on Guard outage) | fail_open (allow on Guard outage)
advisory_mode:     true = log all, block nothing (overrides enforcement_mode)
notify_on_block:   true = send Slack alert when a tool call is blocked
notify_on_budget:  true = send Slack alert when spend budget threshold is hit
deny_on_error:     true = block tool call if Guard evaluation errors (same as fail_closed but per-request)

When user asks to "turn on advisory mode" → set advisory_mode: true
When user asks to "enable blocking" or "go active" → set enforcement_mode: "active"
When user asks to "go fail-open" → set fail_mode: "fail_open"
